# Pop 'n Quack Game 🦆

**Pop 'n Quack** เป็นมินิเกมสไตล์Arcade ที่พัฒนาด้วยโปรแกรม **Processing** (ภาษา Java) โปรเจกต์นี้เป็น Final Project ที่จัดทำขึ้นเพื่อฝึกทักษะการเขียนโปรแกรมเชิงวัตถุ (OOP) การจัดการคลาส (Class) และการสร้างแอนิเมชันกราฟิก 2 มิติพื้นฐาน


โปรเจกต์นี้เป็นการทำงานร่วมกันของสมาชิก 3 คน

## 🎮 How to Play

ระบบเกมถูกออกแบบมาคล้ายกับเกม "ตีตุ่น" แต่เปลี่ยนบรรยากาศเป็นผิวน้ำที่มีเป็ดและสิ่งของต่างๆ โผล่ขึ้นมาให้ผู้เล่นคลิก

1. **เลือกระดับความยาก:** ในหน้าเมนูหลัก ผู้เล่นสามารถเลือกระดับความยากได้ 3 ระดับ (Easy, Medium, Hard) ซึ่งจะส่งผลต่อความเร็วและจำนวนของเป็ดที่ปรากฏบนหน้าจอ
2. **กติกาการทำคะแนน:** ภายในเวลา **30 วินาที** ผู้เล่นจะต้องใช้เมาส์คลิกที่เป็ดที่โผล่ขึ้นมาบนผิวน้ำให้ทันเวลาโดยมีกติกาการให้คะแนนดังนี้:
   * 🦆 **เป็ดธรรมดา:** เมื่อคลิกโดนจะได้คะแนน +1 คะแนน
   * 🐸 **กบพิเศษ:** บางครั้งจะมีกบพิเศษโผล่ขึ้นมา เมื่อคลิกโดนจะได้คะแนนโบนัส +20 คะแนน
   * 💣 **ระเบิด:** ต้องระวัง! หากเผลอไปคลิกโดนระเบิด จะถูกหักคะแนน -10 คะแนน (คะแนนจะไม่ลดต่ำกว่า 0)
3. **เอฟเฟกต์:** เมื่อผู้เล่นคลิกโดนเป็ด กบ หรือระเบิด วัตถุนั้นจะเกิดเอฟเฟกต์ "สั่น" เล็กน้อยก่อนที่จะหายไป
4. **จบเกม:** เมื่อเวลาหมดลง หน้าจอจะแสดงหน้า Game Over พร้อมสรุปคะแนน ที่ทำได้ในรอบนั้น และแสดงสถิติคะแนนสูงสุดของแต่ละระดับความยากที่ถูกบันทึกไว้ในระบบผู้เล่นสามารถกดปุ่ม Restart เพื่อเล่นใหม่ หรือกลับไปที่ Main Menu ได้[cite: 25, 30]

## 📂 Class Architecture

ระบบถูกออกแบบโดยแบ่งการทำงานออกเป็น 8 ไฟล์หลัก เพื่อให้ง่ายต่อการจัดการ:

1. **`Duckgamemain`**: คลาสหลัก (Main) ที่ใช้รวบรวมฟังก์ชันทั้งหมด ตั้งค่าหน้าจอ (800x800 พิกเซล), เรียกใช้งานหน้าเมนู, จัดการ Game Loop (Draw), และระบบตรวจสอบการคลิกเมาส์ 
2. **`Config`**: เก็บตัวแปรตั้งค่าพื้นฐานของเกม เช่น เวลาที่เหลือ, คะแนนปัจจุบัน, สถิติคะแนนสูงสุด, สีของเป็ด, และการตั้งค่าปุ่ม
3. **`ScoreManager`**: จัดการเรื่องคะแนน คอยตรวจสอบและอัปเดตสถิติคะแนนสูงสุด พร้อมระบบบันทึกและโหลดคะแนนจากไฟล์ `.txt` 
4. **`UI`**: จัดการวาดหน้าต่างอินเทอร์เฟซผู้ใช้งาน เช่น หน้าเมนูหลัก และหน้าจบเกม 
5. **`Duck`**: คลาสหลักสำหรับควบคุม "เป็ด" จัดการพฤติกรรมการโผล่ขึ้นและหดลง การสุ่มตำแหน่ง การสุ่มเวลาปรากฏ และการตรวจสอบว่าผู้เล่นคลิกโดนหรือไม่
6. **`Bomb`**: คลาส "ระเบิด" ที่สืบทอด คุณสมบัติมาจากคลาส Duck (การทำงานแบบ Inheritance) แต่ปรับเปลี่ยนคะแนนให้ติดลบเมื่อถูกคลิก
7. **`DuckDrawing`**: รวมฟังก์ชันกราฟิกสำหรับวาดรูปทรงต่างๆ โดยเฉพาะ เช่น การวาดเป็ดธรรมดา (`drawCuteDuck`) และการวาดกบพิเศษ (`drawFrog`)
8. **`Wave`**: คลาสสำหรับสร้างแอนิเมชัน "คลื่นน้ำ" พื้นหลังที่เคลื่อนไหวอย่างเป็นธรรมชาติ โดยใช้ฟังก์ชันทางคณิตศาสตร์ Sine Wave ทำให้กราฟิกดูมีชีวิตชีวา

## Tech Stack
* **ภาษา:** Java
* **โปรแกรม:** Processing 4 (IDE)
* **คอนเซปต์หลัก:** Object-Oriented Programming (OOP), Inheritance (การสืบทอดคลาสของระเบิดจากเป็ด), File I/O (การบันทึกคะแนน)

## 🚀 วิธีการรันโปรเจกต์ (How to Run)
1. ติดตั้งโปรแกรม [Processing](https://processing.org/download) ลงบนเครื่องคอมพิวเตอร์ของคุณ
2. ดาวน์โหลดโปรเจกต์นี้ หรือ `git clone` ลงมาที่เครื่อง
3. ดับเบิลคลิกเปิดไฟล์ `Duckgamemain.pde` ด้วยโปรแกรม Processing (ไฟล์ย่อยอื่นๆ ภายในโฟลเดอร์เดียวกันจะถูกเปิดขึ้นมาโดยอัตโนมัติ)
4. กดปุ่ม **Run** (สัญลักษณ์ Play สีด้านบนซ้าย) เพื่อเริ่มเล่นเกมได้ทันที
